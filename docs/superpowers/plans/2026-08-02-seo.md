# SEO and AI-Search Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a one-page portfolio into a small structured site that ranks for client-intent queries, resolves as a single entity, and gives AI answer engines something specific enough to cite.

**Architecture:** The homepage keeps its structure. Four `/work/<slug>` case studies are added, grounded in the actual project repositories. One `@id` JSON-LD graph, built in `lib/seo.ts`, spans every route so four pages resolve to one person. Canonical host moves to `www`. `robots.txt` becomes an explicit AI-crawler policy.

**Tech Stack:** Next.js 16 (App Router, React 19), TypeScript 5, Tailwind CSS 3.4, `next/font`, `cwebp`, Playwright (verification only, from the scratchpad — not a project dependency).

## Global Constraints

- **Canonical host is `https://www.derbalajr.com`.** Not the apex. Vercel 308-redirects the apex to www, so the apex must not appear in any canonical, `og:url`, JSON-LD `@id`, sitemap entry or robots directive.
- **Confidentiality, per the spec:** Akaza and Rahwan get full engineering depth. **The Address Investments stays conservative** — scale, domains owned, stack, outcome only; no internal architecture, data model or process detail. Delecato covers only what is observable on the public storefront.
- **Nothing is invented.** Every claim traces to a repository file, the live product, or existing site copy. Where a repo contradicts the site copy, the user resolves it — see Task 6 Step 3.
- **Every case study is reviewed and approved by the user before it is committed.** Hard gate, not a suggestion.
- **Case study length: 400–800 words** of visible text. Below 400 the page is not worth having.
- **No `Review` or `AggregateRating` schema anywhere.** Google's structured data policy prohibits self-serving review markup and it carries manual-action risk.
- **No test framework exists in this repo and this plan does not add one.** Per-task verification is `npm run typecheck && npm run lint && npm run build` plus the explicit assertions in each task.
- **`next.config.mjs` sets `typescript.ignoreBuildErrors: true`,** so `npm run build` does not catch type errors. `npm run typecheck` must be run separately, every time.
- **Branch is `seo-2026`.** Commit after every task. Do not push.

### On the `<...>` tokens in Tasks 6–9

The case-study data files carry `<...>` and `<two or three sentences>` tokens
where prose goes. These are **not** unfinished planning. The prose cannot be
pre-written here for two reasons: it depends on reading repositories that this
plan tells the implementer to read, and in Akaza's case it depends on the
answer to a blocking question about which domains are actually built. Writing
invented prose into this plan would be worse than leaving the slot — it would
risk being copied verbatim as fact onto a public page.

What *is* fully specified: the exact files to read, the confirmed facts
available from them, the section headings, the word budget, the confidentiality
boundary, a blocking user-review gate, and a `grep` in each task's verify step
that fails if a token survives into a commit.

## Task 3: robots.txt — explicit AI crawler policy

**Files:**
- Modify: `app/robots.ts`

**Interfaces:**
- Consumes: nothing.
- Produces: a `robots.txt` with named agent rules.

- [ ] **Step 1: Replace `app/robots.ts`**

```ts
import type { MetadataRoute } from "next";

// Named rather than left to a wildcard. Accidentally blocking OAI-SearchBot
// is the single highest-impact AI-visibility error, and a bare "Allow: /"
// leaves that outcome to luck rather than intent.
const SEARCH_AND_ANSWER_BOTS = [
  "Googlebot",
  "Google-Extended",
  "Bingbot",
  "OAI-SearchBot",
  "ChatGPT-User",
  "ClaudeBot",
  "Claude-User",
  "PerplexityBot",
  "Applebot",
  "Applebot-Extended",
];

// Bytespider reportedly accounts for the overwhelming majority of AI crawler
// traffic while widely ignoring robots.txt, so this is a statement of intent
// rather than an enforcement mechanism. CCBot is training-only with no
// citation benefit.
const BLOCKED_BOTS = ["Bytespider", "CCBot"];

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      { userAgent: "*", allow: "/" },
      ...SEARCH_AND_ANSWER_BOTS.map((userAgent) => ({ userAgent, allow: "/" })),
      ...BLOCKED_BOTS.map((userAgent) => ({ userAgent, disallow: "/" })),
    ],
    sitemap: "https://www.derbalajr.com/sitemap.xml",
    host: "https://www.derbalajr.com",
  };
}
```

/** Renders a JSON-LD object into the script tag search engines look for.
 *  Deliberately knows nothing about schema — callers build the object. */
export default function JsonLd({ data }: { data: object }) {
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(data) }}
    />
  );
}

```ts
import type { MetadataRoute } from "next";
import { caseStudyList } from "@/data/case-studies";
import { SITE_URL, SITE_UPDATED } from "@/lib/seo";

// lastModified comes from an explicit date on each case study rather than
// new Date(), which claimed every page changed on every deploy — a freshness
// signal that was simply false. Not derived from git either: Vercel builds
// from a shallow clone, so every file would report the same commit date.
export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: SITE_URL,
      lastModified: new Date(SITE_UPDATED),
      changeFrequency: "monthly",
      priority: 1,
    },
    ...caseStudyList.map((study) => ({
      url: `${SITE_URL}/work/${study.slug}`,
      lastModified: new Date(study.updated),
      changeFrequency: "yearly" as const,
      priority: 0.8,
    })),
  ];
}
```

- [ ] **Step 2: Write the audit script**

Create `/tmp/seo-check.mjs`:

```js
import { chromium } from "playwright";

const BASE = "http://localhost:3000";
const PATHS = [
  "/",
  "/work/the-address-investments",
  "/work/akaza-travel",
  "/work/rahwan",
  "/work/delecato",
];

const b = await chromium.launch();
let fails = 0;
const fail = (m) => { console.log("  FAIL: " + m); fails++; };
const titles = new Set();
const descs = new Set();

for (const path of PATHS) {
  const p = await (await b.newContext({ viewport: { width: 1440, height: 900 } })).newPage();
  const res = await p.goto(BASE + path, { waitUntil: "networkidle" });
  await p.waitForTimeout(1200);

  const a = await p.evaluate(() => ({
    status: 0,
    title: document.title,
    desc: document.querySelector('meta[name="description"]')?.content || "",
    canonical: document.querySelector('link[rel="canonical"]')?.getAttribute("href") || "",
    h1s: [...document.querySelectorAll("h1")].map((h) => h.textContent.trim()),
    levels: [...document.querySelectorAll("h1,h2,h3,h4")].map((h) => +h.tagName[1]),
    words: document.body.innerText.replace(/\s+/g, " ").trim().split(" ").length,
    jsonld: [...document.querySelectorAll('script[type="application/ld+json"]')].map((s) => s.textContent),
    internal: [...document.querySelectorAll('a[href^="/"]')].map((a) => a.getAttribute("href")),
  }));

  console.log(`\n=== ${path} (${res.status()}) ===`);
  console.log(`  title ${a.title.length}ch  desc ${a.desc.length}ch  words ${a.words}`);
  console.log(`  canonical ${a.canonical}`);

  if (res.status() !== 200) fail(`status ${res.status()}`);
  if (a.title.length === 0 || a.title.length > 60) fail(`title length ${a.title.length}`);
  if (titles.has(a.title)) fail("duplicate title"); else titles.add(a.title);
  if (descs.has(a.desc)) fail("duplicate description"); else descs.add(a.desc);
  if (!a.canonical.startsWith("https://www.derbalajr.com")) fail(`canonical ${a.canonical}`);
  if (a.h1s.length !== 1) fail(`${a.h1s.length} h1 elements`);
  for (let i = 1; i < a.levels.length; i++)
    if (a.levels[i] > a.levels[i - 1] + 1) fail(`heading skip h${a.levels[i - 1]}->h${a.levels[i]}`);
  if (path !== "/" && (a.words < 400 || a.words > 800)) fail(`word count ${a.words}`);

  // JSON-LD must parse, and every referenced @id must exist in the graph.
  const ids = new Set(), refs = [];
  for (const raw of a.jsonld) {
    let parsed;
    try { parsed = JSON.parse(raw); } catch { fail("JSON-LD does not parse"); continue; }
    const walk = (n) => {
      if (Array.isArray(n)) return n.forEach(walk);
      if (!n || typeof n !== "object") return;
      if (n["@id"] && n["@type"]) ids.add(n["@id"]);
      else if (n["@id"]) refs.push(n["@id"]);
      Object.values(n).forEach(walk);
    };
    walk(parsed);
  }
  for (const r of refs) if (!ids.has(r)) fail(`dangling @id reference ${r}`);
  console.log(`  jsonld: ${ids.size} nodes, ${refs.length} refs, all resolve: ${refs.every((r) => ids.has(r))}`);

  await p.context().close();
}

// Every internal link must resolve.
const p = await (await b.newContext()).newPage();
for (const path of PATHS) {
  await p.goto(BASE + path, { waitUntil: "domcontentloaded" });
  const links = await p.$$eval('a[href^="/"]', (as) => [...new Set(as.map((a) => a.getAttribute("href")))]);
  for (const href of links) {
    if (href.endsWith(".pdf")) continue;
    const r = await p.request.get(BASE + href.split("#")[0]);
    if (r.status() !== 200) fail(`${path} -> ${href} returns ${r.status()}`);
  }
}

for (const f of ["/robots.txt", "/sitemap.xml", "/llms.txt"]) {
  const r = await p.request.get(BASE + f);
  console.log(`\n${f}: ${r.status()}`);
  if (r.status() !== 200) fail(`${f} returns ${r.status()}`);
}

await b.close();
console.log(`\n${fails === 0 ? "ALL CHECKS PASSED" : fails + " CHECK(S) FAILED"}`);
process.exit(fails === 0 ? 0 : 1);
```
