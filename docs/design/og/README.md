# Open Graph card

`public/og.webp` — the 1200×630 image link previews show for derbalajr.com.

The wireframe background (`plate.webp`) was generated with Gemini; everything
else is real text, rendered by a headless browser in the site's own fonts and
tokens, so the type stays crisp and can't drift from the site.

## Regenerating

Needs Playwright with Chromium and `cwebp` on PATH.

```bash
cd docs/design/og
npm i playwright && npx playwright install chromium
node og.mjs ./plate.webp ./og.png
cwebp -q 88 -resize 1200 630 ./og.png -o ../../../public/og.webp
```

Edit the copy in `og.html`. Keep it to two or three lines — the card is read as
a thumbnail more often than at full size.

## Notes

- `.patch` in `og.html` covers the generator's ✦ brand glyph, which sits in the
  gap between the blue core and the teal shell. It can't be cropped out without
  cutting the orb.
- `.scrim` darkens the left side so the type stays legible over the glow that
  bleeds in from the orb.
- The card is *not* `Person.image` in the JSON-LD — that stays the portrait
  (`/omar.webp`), since schema.org wants an image of the person there.
- `public/apple-touch-icon.png` (180×180, the OD mark) is generated by the same
  approach; the inline snippet lives in the commit that added it.
